# Wordle

A command-line Wordle game in C where you guess a 5 letter word.

Features:
- 2 gamemodes
- Coloured words to assist in guessing.
- 10000+ challenging words

----

## Running

You need to have a C compiler installed (GCC for makefile)

### Step 1: Clone the Repository
```bash
git clone https://github.com/mattng1016/wordle.git
```

### Step 2: Move to the installed directory
```bash
cd wordle
```

### Step 3: Compile the Game
```bash
make run
```
