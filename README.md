# Wordle

A command-line Wordle game in C.

## How to Play

- Guess a 5-letter word
- After each guess, you'll see:
  - 🟢 Green: correct letter in correct position
  - 🟡 Yellow: correct letter in wrong position
  - 🔴 Red: letter not in word
- Choose between standard (5 guesses) or unlimited guesses mode

## Build & Run
make run
